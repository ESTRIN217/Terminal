Uso de la terminal

Gestos, teclado, multipantalla, menú «Más» y depuración.

El entorno Debian

Cada pestaña de terminal es una sesión dentro de un entorno Debian completo vía proot. Puedes usar apt para instalar paquetes con apt install <paquete>, y herramientas normales de una distribución Linux dentro del almacenamiento de la app. La conexión a internet solo hace falta para apt: el resto funciona sin red.

Sesiones y multipantalla

  • Pestañas: cada sesión de terminal (o pestaña del gestor de archivos) es una pestaña; puedes tener varias a la vez.
  • Split: en pantallas de 600 dp o más puedes repartir dos paneles simultáneos (terminal o gestor de archivos). Tocar un panel lo enfoca sin moverlo; cerrarlo o rotar el dispositivo lo deshace.
  • Gestor de archivos: pestaña dedicada, con symlinks, papelera, marcadores, iconos por tipo de fichero, topbar con breadcrumb y menú «Organizar», selección en la topbar y acciones sobre los archivos (copiar ruta, compresión zip/tar.xz/7z, propiedades con permisos, edición con nano/vim, abrir terminal en el directorio actual…).

Teclado

  • IME de Android + barra de teclas extra (macros, popup de teclas especiales, estilos extra-keys-style de Termux).
  • Selección: long-press para marcar, handles arrastrables y toolbar Copiar/Pegar/Más (en el renderer nativo de Compose; detrás del flag native_compose_renderer).
  • Scroll: pinch-zoom e inercia de scroll en el renderer nativo, scrollwheel del ratón físico también funciona.
  • BACK: con selección activa la limpia; sin selección se comporta como tecla Esc del terminal si así lo tienes configurado.

Teclas extra

La barra de teclas extra sale bajo el teclado cuando la sesión está activa. Sirve para escribir caracteres que el teclado virtual no verá bien (por ejemplo Esc, Tab, Ctrl combinados). Se configura por sesión, no por pantalla.

Menú «Más» (More)

¿Dónde sale? Acciones destacadas
Overflow (MoreVert) en la pestaña de terminal activa, botón «Más…» de la toolbar de selección y right-click del ratón. Compartir texto seleccionado · Seleccionar URL · Autofill · Matar proceso · Mantener pantalla encendida.

El menú es un ModalBottomSheet de [Material 3 Expressive]; la hoja de selección de URL (ver Hipervínculos) es un diálogo cuyo título explica las dos acciones posibles: «Click URL to copy or long press to open».

Depuración

Puedes ajustar el nivel de logcat desde Ajustes → Terminal → Debugging → Log Level (por defecto Normal).

Nivel Qué registra
OffNo registra nada.
NormalErrores, avisos, info y stacktraces.
DebugMensajes de depuración.
VerboseMensajes detallados.

Consúltalo con logcat -d desde la propia terminal o con adb logcat desde un PC. Vuelve a Normal cuando acabes de depurar.

Reporte de incidencias

  1. Menú largo del terminal → More → Report Issue: genera un reporte automático.
  2. Pública el texto completo en un issue de este fork.
  3. Los issues con solo capturas de pantalla parciales probablemente se cierren.
