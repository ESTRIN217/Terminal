Terminal is a terminal emulator application that brings a Linux command line experience to Android devices with no rooting or other special setup required.

* Enjoy the Bash shell in a bundled Debian environment.
* Edit files with nano and vim.
* Access servers over SSH.
* Check out projects with Git.
* Run text-based programs.

At first start a Debian rootfs is downloaded and configured with proot. Core utilities are available out-of-box and additional software can be installed with the Debian package manager (apt).

To learn more about application usage tips and tricks, long-press anywhere on the terminal and select the Help menu option, or visit https://github.com/ESTRIN217/Terminal/wiki.

Terminal is an independent fork. It is not affiliated with, endorsed by, or supported by the Termux team.
